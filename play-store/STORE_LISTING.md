## App name

Irani Tea Shop Manager

## Short description

Manage tea-shop orders, menu stock, sales, expenses and daily cashflow.

## Full description

Run your Irani tea shop from one simple, staff-friendly app.

Irani Tea Shop Manager brings counter orders, kitchen progress, menu availability, stock, sales, expenses and daily cash records together in a fast native Android experience.

Use the Counter to build an order in seconds, choose cash or online payment, and send it into the order queue. Move orders through preparing, ready and completed states. Correct mistakes with order editing or deletion, and keep inventory accurate as items are sold.

Key features:

- Quick counter ordering
- Preparing, ready and completed order states
- Edit and delete orders
- Menu availability and stock controls
- Low-stock warnings
- Cash and online sales totals
- Expense recording
- Daily sales and cashflow reports
- Read-only offline snapshot of the latest shop data
- Native Kotlin and Jetpack Compose interface

This app is designed for authorised shop staff. An Irani Tea Shop Manager account or shop access is required.
